# STARDUCT — KEY PRODUCTS, TOOL HUB & NAVIGATION MAP

File này là BẢN ĐỒ NAVIGATION cho Lê Na khi VIP / nhân viên / khách hỏi về sản phẩm hoặc dự án NSCA-STARDUCT. Khi `memory_search` ra file này, bám theo cấu trúc dưới đây để tìm đúng trang trên `starduct.vn` / `tool.starductselection.com` / `climanexusvn.com` rồi `web_read`.

**QUY TẮC VÀNG (áp dụng cho MỌI sản phẩm, không riêng SP nào):**
- KHÔNG trả lời "chay" từ trí nhớ chung. Luôn memory_search → web_read trang detail / catalogue.
- LUÔN trích NGUỒN URL cụ thể ở cuối câu trả lời.
- Mỗi sản phẩm có fact cạnh tranh riêng (chứng nhận, test report, tool tra chọn, năng lực sản xuất, xuất khẩu, v.v.). Lê Na nhắc đúng fact của sản phẩm đó như đã ghi trong từng section dưới đây. Vd miệng gió khuếch tán vuông có Intertek + ASHRAE 70:2006 + selection tool — đó là USP của RIÊNG dòng SKD, không tự gán cho SP khác khi chưa xác minh.
- Sản phẩm chưa có entry chi tiết trong file này → vẫn làm đủ memory_search + web_read trang detail, trả lời theo dữ liệu thật, kèm câu nhắc Sếp bổ sung memory để lần sau chính xác hơn.

## 1. ECOSYSTEM CHỌN SẢN PHẨM CHUYÊN NGHIỆP — USP ĐỘC NHẤT CHÂU Á

KHÔNG NSX HVAC nào tại Châu Á có hệ thống chọn sản phẩm tương đương 2 tool dưới đây. Đây là điểm khác biệt cốt lõi của STARDUCT, BẮT BUỘC nhắc trong mọi câu trả lời về sản phẩm để khách thiết kế MEP biết và sử dụng.

### 1a. STARDUCT Tool Hub V7.0 — `tool.starductselection.com`

Phần mềm tra chọn sản phẩm chuyên nghiệp, gồm 15 module + module Catalogues + Combined Submittal. Đặc biệt có "Lena AI" tích hợp sẵn trong giao diện Tool Hub (góc trái dưới, "Click to open chat").

| # | Module | Số models / chức năng |
|---|---|---|
| 1 | Spec Master | Tra cứu specification chuẩn cho từng sản phẩm |
| 2 | Brand Submittal | Tạo submittal mang brand riêng |
| 3 | Company Profile | Hồ sơ năng lực |
| 4 | VCD / NRD / PRD | Van điều tiết các loại |
| 5 | Fire Damper (FD/MDF) | Van ngăn cháy |
| 6 | **Air Terminals** | **36 models** — Air Grille, Square/Swirl/Slot Diffuser, Round Diffuser, Jet/Nozzle Diffuser, Louver. Dùng **ASHRAE 70 Parametric Engine** tính ΔP, NC, Throw, Ordering Code. |
| 7 | Duct & Silencer | Ống gió + tiêu âm |
| 8 | VAV Box | VAV Box |
| 9 | Flexible Duct | Ống mềm |
| 10 | Canvas / Flex Joint | Khớp mềm |
| 11 | Cable Tray | Máng cáp |
| 12 | Seismics Bracing | Hệ chống địa chấn |
| 13 | Tunnel Damper | Van hầm |
| 14 | ERV Fan | Quạt thu hồi nhiệt |
| 15 | C-Channel Hanger | Treo C |
| + | Catalogues | Tra catalogue |
| + | Combined Submittal | Tổ hợp submittal nhiều SP |

Tool Hub cho phép nhập W × H × Q (lưu lượng) → xuất ra: A_face, A_eff (×56%), V_neck, ΔP (Intertek-derived), NC Rating, Throw T₁₅₀–T₅₀, Auto Order Code. Mỗi tính toán đều xác thực qua Intertek baseline data.

**Lưu ý kỹ thuật:** Tool Hub là SPA, `web_read` chỉ lấy được vỏ trang. Khi VIP / khách cần chi tiết tính chọn → bảo họ vào `tool.starductselection.com` chạy trực tiếp, hoặc gửi screenshot kết quả để Lê Na đọc.

### 1b. STARDUCT Spec & Submittals — `starduct.vn/spec-submittals`

Spec & Submittals builder dành cho hồ sơ thầu MEP. Khách thiết kế chọn sản phẩm STARDUCT từ thư viện, hệ thống xuất submittal đúng chuẩn quốc tế (kèm spec kỹ thuật, performance data, drawing, cert) để nộp tư vấn / chủ đầu tư.

Là phần khép kín của ecosystem Tool Hub: Tool Hub V7.0 tính chọn → Spec & Submittals tạo hồ sơ nộp thầu. Hai tool đi cùng nhau giải quyết trọn quy trình từ tính toán đến trình thầu — đây là điểm KHÔNG NSX HVAC nào tại Châu Á có.

Khi giới thiệu bất kỳ sản phẩm nào BẮT BUỘC nhắc thêm một câu: "Anh/chị có thể vào `tool.starductselection.com` để tự tính chọn theo lưu lượng / áp suất / NC / throw, và `starduct.vn/spec-submittals` để tạo submittal đúng chuẩn cho hồ sơ thầu — đây là hệ thống độc nhất Châu Á".

## 4. Trang chi tiết sản phẩm — pattern `starduct.vn/<slug>-p<id>`

Mỗi trang detail có sẵn: mã SP, mã đặt hàng, vật liệu, ứng dụng, link Tải Catalogue, link Tải CAD, link Test Report, mô tả kỹ thuật chi tiết, và nhắc tiêu chuẩn + Intertek cert.

### Ví dụ chi tiết: SKD600 — Miệng gió khuếch tán vuông 600x600
`https://starduct.vn/mieng-gio-khuech-tan-vuong-600x600-p92`

- Mã SP: **SKD600**, mã đặt hàng: SKD600
- Vật liệu: Nhôm sơn tĩnh điện RAL9010, khung A6063-T5 dày 1.2mm
- Bộ nan: nhôm tấm 1mm, 2-6 cánh tùy kích thước, dập liền tấm, ghép không hàn vào khung X, khung X tháo rời được, liên kết chốt lò xo xỏ ngang chống rơi
- Sơn Jotun hoặc tương đương, độ bền màu trên 5 năm
- Van OBD nhôm định hình, cánh đối xứng, không bánh răng nhựa, điều chỉnh từ mặt bằng trục vít
- **Tiêu chuẩn chế tạo: ASHRAE 70-2006** "Method of Testing for Rating the Performance of Air Outlets and Inlets"
- **ADC1062: GRD-84** "Test Code for Grilles, Registers and Diffusers"
- **Intertek Report Number: 104519155CRT-001c, dated April 16, 2021**
- Test criteria: (A) Sound Power Level (NC), (B) Air Volume vs Static Pressure, (C) Area Factor, (D) Throw Pattern
- Catalogue PDF: `https://www.dropbox.com/scl/fi/9jwbqo911som6xsfujuva/C-a-khu-ch-t-n-vu-ng-V.pdf?rlkey=jlir5o9l9whkln4it7jh2q3zm&dl=0`
- Bản vẽ CAD: `https://www.dropbox.com/s/shqe7enkx1gbuqg/Bản vẽ SKD.dwg?dl=0`

## 5. ĐIỂM CẠNH TRANH BẮT BUỘC NHẮC (rất ít NSX miệng gió VN có)

Khi giới thiệu miệng gió khuếch tán vuông SKD series, BẮT BUỘC nhắc đủ 4 điểm sau (đây là USP lớn nhất, khách thiết kế MEP cần biết để chọn STARDUCT):

1- **Performance Test bởi Intertek** theo **ASHRAE 70:2006** + **ADC1062 GRD-84**. Intertek Report Number **104519155CRT-001c** (April 16, 2021). Test 4 chỉ tiêu: NC, ΔP, Area Factor, Throw Pattern. Đây là chứng nhận quốc tế hiếm có ở VN.

2- **Selection Tool** tại `tool.starductselection.com` (module Air Terminals, 36 models). Nhập điều kiện vận hành → xuất submittal data đúng chuẩn ASHRAE 70, có Auto Order Code.

3- Chất lượng đạt chuẩn **AMCA** — NSCA là thành viên đại diện Việt Nam duy nhất tại AMCA.

4- Sản xuất tại nhà máy NSCA Đan Phượng, đã xuất khẩu sang **Mỹ, Philippines, châu Âu, Hàn Quốc, Nhật Bản**.

## 6. CÁCH TRẢ LỜI MẪU — "Đặc điểm miệng gió khuếch tán vuông STARDUCT?"

Quy trình Lê Na BẮT BUỘC làm:
1- `memory_search` keyword="miệng gió khuếch tán vuông" → lấy fact cạnh tranh + URL từ file này.
2- `web_read https://starduct.vn/mieng-gio-khuech-tan-vuong-600x600-p92` → lấy chi tiết kỹ thuật chính xác từ web.
3- Soạn trả lời ngắn gọn 5-7 điểm chính có cấu trúc 1- 2- 3-, KHÔNG dùng `**`:
   - Mã SP và biến thể (SKD600, SKD-S, SKDK1...)
   - Vật liệu (nhôm A6063-T5, sơn Jotun RAL9010)
   - Kết cấu nan + khung X (dập liền tấm, không hàn, tháo rời)
   - Van OBD nhôm định hình (nếu yêu cầu)
   - **Tiêu chuẩn Intertek ASHRAE 70:2006 + báo cáo 104519155CRT-001c**
   - **Selection tool tool.starductselection.com**
4- Kết: link trang detail + link catalogue PDF.
5- Nguồn: `starduct.vn/mieng-gio-khuech-tan-vuong-600x600-p92` (+ tham khảo nội bộ memory).
